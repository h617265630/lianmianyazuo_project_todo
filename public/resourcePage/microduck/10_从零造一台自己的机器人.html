10 · 从零造一台自己的机器人——一份"创业指南"式的工程化路径

面向想从仿真走到真机的工程师 / 研究员 / 学生。

0. 总原则

原则解释为什么
先仿真，再半实物，最后真机第一版策略必须在 sim 里跑出能看的录像仿真失败 0 元，真机失败 200 元+受伤风险
从轮式到腿式差速驱动底盘 + 简单 RL → 桌面腿式 → 自研双足失败半径递增，先把 RL/部署链路打通
复用现成 BOMStanford Pupper / SO-ARM100 / Solo12 BOM 全公开自研 = 集成，不是从零画 PCB
训推同栈训练用 mjlab + PPO，部署用 ONNX Runtime不同栈必崩

阶段 0：纯仿真（$0，1–2 周）

目标：把 RL 链路跑通——能训一个在仿真里"会走"的策略，不碰任何硬件。

5. 阶段 5：产品化（如果你想做出货，$10k+，24 周+）

  • 机械工程化：外观 CMF 设计、跌落 / IP 等级、可制造性（DFM）
  • 软件工程化：OTA（systemd + signed firmware）、Daemon、App
  • 测试与认证：FCC / CE / 蓝牙认证（~$3k–10k）、EMC 测试、跌落 / 振动

9. 常见失败模式 + 对策

失败模式症状对策
硬件到不了仿真精度仿真走得好，真机摔跤DR 必须覆盖质量 / 摩擦 / 延迟 / 间隙
训练时长不够跑了 200 iter 没收敛就放弃简单 episodic ≈ 1000 iter；gaits ≈ 4000–6000 iter
通信延迟失控50 Hz 控制却用了 30 ms ROS2仿真里直接训 latency-DR；真机走 UART + 共享内存
电池续航不足5 分钟就掉链先测满载电流，再算 mAh / 平均电流 × 0.7
ONNX 不一致仿真精度 OK，ONNX 跑偏normalizer 必须 baked-in
