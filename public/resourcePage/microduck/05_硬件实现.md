## 2. 主板 / 计算单元

> 这部分是公开信息 + 仓库 XML 印证。

| 部件 | 规格 | 备注 |
|---|---|---|
| SoC | Rockchip **RK3566** | 4× Cortex-A55 @ 1.8 GHz |
| GPU | Mali-G52 | 仅用于可能的 ISP / 显示 |
| NPU | 0.8 TOPS | 可选用于本地语音 / 视觉 |
| VPU | 4Kp60 H.265 解码 | WebRTC 流媒体用 |
| RAM | 1 GB LPDDR4 | |
| 存储 | 32 GB eMMC | 装系统 + 策略 |
| 控制频率 | **50 Hz** | 仓库文档（`AGENTS.md`） |

**为什么是 RK3566 而不是 Raspberry Pi 4 / Jetson？**

- 便宜（~$15 vs $60+ for Jetson）
- 功耗低（RK3566 全核 ~3W vs Jetson 7–15W）
- 50 Hz 推理 14 维 ONNX，CPU 完全够
- 内置 NPU 留给未来的视觉 / 语音

**为什么 NPU 才 0.8 TOPS？**

- 当前任务**只用 IMU + 关节角**，不需要 GPU/NPU
- 0.8 TOPS 留给**未来的视觉策略 / 语音唤醒**——生态预留

## 3. 伺服系统（重点）

### 3.1 Dynamixel XL330-M288-T

仓库里 `microduck_constants.py` 直接说 `servos = "xl330"`。

| 参数 | 值 |
|---|---|
| 电机 | 空心杯有刷 DC |
| 齿轮 | 金属 + 塑料混合（推测）★ |
| 编码器 | 12-bit 磁编（4096 分辨率） |
| 通信 | TTL 半双工总线（daisy chain） |
| 协议 | Dynamixel Protocol 2.0 |
| 力矩 | ~0.42–0.6 N·m |
| 控制模式 | 电流 / 位置 / 速度 / PWM |
| 内置 MCU | Cortex-M0+（板级电流 / 位置环） |

### 3.2 14 个伺服的关节映射

来自仓库 `microduck_constants.py`（按 ctrl 索引顺序）：

```
0  left_hip_yaw      ┐
1  left_hip_roll      │
2  left_hip_pitch     │ 左腿 5 个
3  left_knee          │
4  left_ankle        ┘
5  neck_pitch        ┐
6  head_pitch         │ 脖子 / 头 4 个
7  head_yaw          │
8  head_roll         ┘
9  right_hip_yaw     ┐
10 right_hip_roll    │
11 right_hip_pitch   │ 右腿 5 个
12 right_knee        │
13 right_ankle      ┘
```

左右对称分布，**neck + head 占 4 个**——鸭子的"表情"几乎全部靠头颈实现。

### 3.3 鸟喙（额外的 1 个伺服）

产品页明确提到 **articulated beak as a gripper**——鸟喙是一个单自由度的夹爪，
能抓约 800 g 物体。这是仓库 `Microduck-Velocity` 主任务里**第 15 个伺服**，
但在 14DOF 的 standing / walking 任务里**不参与控制**——只是物理上存在。

### 3.4 ★ 总线拓扑推测

Dynamixel 是菊花链，所有伺服串在一根 TTL 总线上：

```
[Main Board UART] ──▶ [servo 0] ──▶ [servo 1] ──▶ ... ──▶ [servo 14]
                  └─── feedback ──┘── feedback ──┘
```

50 Hz × 15 伺服 = 750 个 feedback/s，TTL 速率 1 Mbps 够用（每包 < 200 B）。

## 4. 传感器

### 4.1 IMU（确认）

仓库 `robot/microduck/sensors.xml`：

```xml
<framequat name="orientation" objtype="site" noise="0.001" objname="imu"/>
<gyro name="angular-velocity" site="imu" noise="0.005"/>
```

→ 仿真里是 1 个 IMU site，**真机上推测是 BMI270 / ICM-42607 这类 6 轴**。

### 4.2 第二 IMU（确认存在）

产品页：body 1 个 + head 1 个 = **2 个 6 轴 IMU**。

**为什么需要 2 个？**
- body IMU：走路姿态
- head IMU：分离头部运动 vs 躯干运动 → 知道"它在转头" vs "整个身体倒了"

### 4.3 摄像头

| 参数 | 推测值 ★ |
|---|---|
| 类型 | 前向广角 OV5640 类（5MP） |
| 帧率 | 30 fps |
| 接口 | MIPI CSI |

**当前 RL 训练栈不直接用摄像头**——纯 proprioception（本体感觉）。
摄像头留给未来的视觉策略 / 远程控制 / 视频流。

### 4.4 ToF

产品页：8×8 ToF（推测是 ST **VL53L8CX** 或类似）

- 测距范围：~5 cm – 2 m
- 多区测距：8×8 = 64 个距离点
- **当前 RL 训练栈没用 ToF**——`src/mjlab_microduck/sim/tof.py` 存在但用法有限

### 4.5 麦克风 / 扬声器

- 麦克风：1–2 个 MEMS（推测 SPH0645）
- 扬声器：8Ω 1W 小喇叭（仓库有 `assets/speaker.part`）
- "Per-robot generated voice" → TTS 合成

### 4.6 NFC

| 数量 | 2 个天线 |
| 位置 | 头顶 + 鸟喙 ★ |
| 协议 | ISO 14443A / NFC-A（手机兼容） |

### 4.7 触摸 ★

Dynamixel XL330 有 torque / current feedback → **鸟喙抓东西时能感知到阻力**。
仓库 `microduck_ground_pick_env_cfg.py` 的奖励里很可能用了 torque 反馈（猜的）。

## 5. 电源 / 充电

### 5.1 主电池 NP-F550
- 7.2 V 锂离子
- 2600 mAh ≈ 18 Wh
- 全负荷 ~10 W → ~1 小时续航

### 5.2 ★ 为什么选 NP-F550
- **Sony 标准电池**——和摄影机通用，便宜
- **可拆卸**——快速换电池比充电快
- **2S 锂电**（7.2V 标称）→ 走 5V/3.3V buck 即可
- 同时支持 6.5–8.2V 范围（BAM 训练范围见 `infer_policy.py` `BAM_VIN_RANGE`）

### 5.3 USB-C 充电
- 5V / 2A 充电
- Charger Pack 双充 = 39 美元

## 6. PCB ★ 推测

虽然 Pollen 没开源 PCB（这是社区最失望的点），但从公开信息可以推测布局：

```
┌────────────────────────────────────────────────────────┐
│  [USB-C]      [Speaker]                                │
│                                                        │
│  ┌──────────┐    ┌──────────────────────────────┐    │
│  │ RK3566   │    │ Buck 5V / 3.3V / 1.8V         │    │
│  │ + 1GB    │    │ (from NP-F550 7.2V)          │    │
│  │ + 32GB   │    └──────────────────────────────┘    │
│  └──────────┘                                          │
│       │                                                │
│       ├─ UART ────▶ [XL330 bus] ─── 15 servos          │
│       ├─ I2C ─────▶ 2× IMU                            │
│       ├─ I2C ─────▶ ToF VL53L8CX                      │
│       ├─ I2S ─────▶ MEMS Mic                          │
│       ├─ PWM/DAC ─▶ Speaker amp                       │
│       ├─ SPI  ────▶ eMMC (32GB)                       │
│       ├─ MIPI CSI ▶ Camera                            │
│       └─ GPIO  ───▶ NFC reader (2 antennas)           │
```

**推测的总成本**：RK3566 + 周边 ~$30，15 颗 XL330（按批发价 ~$25/颗算） ~$375
——已经接近整机售价。**真正的价值在软件**。

## 7. 散热 / 防护 ★

- RK3566 满载 ~3W → 自然散热 + 金属躯干外壳导热
- 14 个 XL330 总峰值功耗 ~5–10W → 同样自然散热
- 摔倒冲击：仓库 groundcontact 任务专门训练抗摔；底盘有塑料外壳吸能

## 8. sim2real 的硬件侧难点

| sim2real gap | 仓库里怎么处理 |
|---|---|
| 真实伺服不是位置完美的 | **BAM 模型**——电压控制 + 摩擦模型 |
| 关节有间隙 | **backlash 模型**——`add_backlash.py` 加 ±1° 被动铰链 |
| 电池电压不稳 | `vin_drop_gain` 域随机化 |
| IMU 噪声 | `sensors.xml` 加 `noise="0.001"` |
| 真实摩擦未知 | `foot_friction` 域随机化（PU 鞋底） |
| 视觉没用上 | 纯 proprioception，**避开视觉 gap** |
