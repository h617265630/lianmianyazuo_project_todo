# duck_分析 — Microduck 项目学习笔记本

> 这是一个**边做边学**的目录：你每学到一个点就追加一条笔记（`notes/`），每跑通
> 一个实验就贴一张图或一段日志（`figures/`）。**不需要写得很整齐，先记下来
> 比写得好更重要。**

Microduck 是 Pollen Robotics / Hugging Face 推出的一台 25 cm 高、约 800 g 的开源
双足机器人，全身 14 个 Dynamixel XL330 智能伺服。本仓库 `microduck_rl/` 是它
的官方 RL 训练栈（mjlab + MuJoCo Warp + PPO），真机运行时在
`pollen-robotics/microduck`。

这个目录的目的：**不重复写一遍训练命令**（那些都在 `AGENTS.md` 和 `README.md`
里了），而是把它当作**理解鸭子**的入门引导：

- 把鸭子**为什么这么设计**讲清楚（硬件选型、传感器布局、为什么是 BAM 物理）
- 把 RL 的关键概念**映射到鸭子的具体工程实践**上
- 把"动作"、"姿态"、"对话"、"反应"这些人和机器人交互的概念落到代码 / manifest
- 列出 PCB、伺服控制、IMU / 力矩、强化学习这些**可以继续深入的分支**

## 这台鸭子到底是什么 —— 一句话总结

> 一台**会感知（IMU + 摄像头 + ToF + 触觉）、会思考（ONNX 策略网络 50 Hz）、
> 会执行（14 个位置伺服 + 一个能"抓"的鸟喙）**的双足机器人，全部跑在一个
> RK3566（4×A55）上，整机含电池 800 g，续航约 1 小时，零售价 $399。

这句话里每一个名词都会在后面的文档里展开。

## 你现在能直接做的几件事（按难度递增）

| # | 行动 | 时间 |
|---|---|---|
| 1 | 在 MuJoCo Studio 里打开 `scene.xml`，看看鸭子长什么样 | 30 秒 |
| 2 | `uv run scripts/infer_policy.py --walking out.onnx` 看策略驱动 | 5 分钟 |
| 3 | `uv run train Mjlab-Velocity-Flat-MicroDuck --env.scene.num-envs 64 --agent.max_iterations 5` 跑一个 smoke test | 10 分钟 |
| 4 | 读 `AGENTS.md`，理解 sim2real 的所有 invariant | 1 小时 |
| 5 | 在 `notes/` 写第一篇笔记："今天我看到鸭子倒下时……" | 立刻 |

做完第 3 步以后，回过头来读 `01_训练入门.md`，会顺畅很多。
