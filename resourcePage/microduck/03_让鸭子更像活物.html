03 · 让鸭子更像活物 —— 从"执行命令"到"有生命感"

一个能走 / 能踢 / 能坐的机器依然是机械的。让它"像活物"，是另一层设计。

1. 什么叫"像活物"

不像活物像活物
给指令才动，不给指令就僵住不给指令时晃头、踱步、梳理羽毛
100% 重复同一动作走路时偶尔绊一下、停一下看
一接命令立刻响应假装"思考"一下再执行
永远成功执行偶尔失败——踢偏、没站稳
表情（LED）恒定收到指令时亮眼、摔倒了低头

2. 行为分层的思路

把鸭子的行为想成 3 层金字塔：

          ▲
         /│\         第 3 层：性格 / 个性（idle 动作、声音、LED 节奏）
        / │ \            ↑ 长期不变，但每次执行有微小差异
       /──┼──\
      /  │  \        第 2 层：反应 / 触发（被吓到 → 颤一下）
     /   │   \          ↑ 由事件驱动：声音、触摸、NFC、视觉
    /────┼────\
   / 技能层  \        第 1 层：技能 / 任务（走、踢、鞠躬）
  /─────────────\       ↑ 当前 ONNX 策略

当前仓库已经在第 1 层很扎实；第 2 层主要由 daemon 和外层应用负责；第 3 层基本是空白——这是你最值得发挥的层。

3. 闲置动作（idle behavior）

鸭子不动的时候干嘛？决不能僵直。几种思路：

3.1 头部 idle

训一个 head_idle 策略，或者直接写一个 head 摆动函数 + sinusoidal 命令

3.2 踱步

走路指令加微小的随机扰动，让速度不是 0

3.3 姿态整理

偶尔触发一个 0.5 s 的"伸懒腰" episodic 策略

这些都不需要重新训大策略，只需要在 daemon 加个 idle 调度器。

4. 反应层（reactive layer）

机器人"被吓到"是最经典的活物感来源。真机上有现成的传感器可以用：

传感器触发反应
IMU（自由落体加速度）检测到自由落体缩颈、亮眼（摔倒反射）
ToF（深度）突然有东西靠近抬头看
麦克风突然响声头转向声源
触摸（鸟喙夹爪）被触碰抓住、摆动
NFC读到 NFC 标签触发对应 episodic

6. LED 表达（被忽视的维度）

鸭子 LED 可以表达：

状态颜色 / 节奏
待机呼吸蓝
行走稳态白
摔倒红色闪烁
收到指令绿色脉冲
困惑黄色慢闪
高兴彩虹渐变
这是让鸭子有"表情"最便宜的一招，duck 头顶 + 眼睛（如果有 LED）一起做就能立竿见影。

7. 声音 / 语音

常见的"活物感"声音设计：

  • 音效代替状态：摔倒 → "嘎"，鞠躬 → "嘎嘎"，停止 → 安静
  • 指令反馈：听到"过来" → "嘎！"（确认） → 走过来
  • 咕哝声：闲置时偶尔发一声非常短的"嘎？"
不要做"语音助手"——鸭子是动物感，不是智能音箱。一个"嘎"比"好的，我来走"更可爱。

8. 总结：让鸭子"活"的 5 个具体动作

优先级改动效果
🥇 1LED 颜色映射状态一眼能看出来是活的
🥈 2闲置时 head 微动 + 偶尔踱步不会僵
🥉 3摔倒音效 + 挣扎几下再躺"失败"也是表达
4触碰 / 声音触发反应互动感
5多策略混合编排 + 个体微调个性

前 3 项不需要重新训 RL，纯靠 daemon 编排层就能做出来。
