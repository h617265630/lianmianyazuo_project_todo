# 09 · 机器人项目横向对比 — 项目地图册

> 写给想"动手玩真机"但不知道买谁的你。
> 一份 2025 年视角、按价位排的开源 / 商业机器人项目地图册，
> 帮你在动手之前先想清楚：**想做什么 → 该学哪个项目**。

---

## 1. 写在前面：为什么要做这张表

RL（强化学习）+ 端到端部署最近几年从论文走进桌面：从 `mjlab`/`Isaac Lab` 跑仿真，到 `LeRobot` 一行代码训 SO-ARM100，再到 Hugging Face × Pollen Robotics 的 Microduck 把"会走路的小鸭子"压到 $399。学生、个人开发者、独立研究者终于能用一台笔记本 + 一个机器人跑完整链路。

但问题来了：

- 桌面级（<$500）的有十几款，差异只在"有腿没腿"；
- 商业级（$30k+）的人形 / 四足都在做 demo，互相 cover；
- 价格跨度 4 个数量级，**项目定位完全不同**，选错=浪费时间。

本文按价位 + 形态梳理主流项目，给出"想学 X → 选 Y"的反查表。

## 2. 桌面级（< $500）：从拼装到桌面伴侣

| 项目 | 价格 | 形态 / DOF | 训练方式 | 开源 | 学习曲线 |
|---|---|---|---|---|---|
| **Microduck** | $399 | 双足 14 DOF | 仿真 PPO + ONNX 部署 | Apache 2.0 | 中 |
| **Reachy Mini Lite** | $299 | 桌面头 + 旋转躯干，6+1 DOF | HF Transformers / Python SDK | Apache 2.0 (软件) / CC BY-NC-SA (硬件) | 低 |
| **SO-ARM100** | ~$100–300（DIY） | 5+5 DOF 机械臂 | LeRobot ACT / DP3 / SARM | Apache 2.0 | 低 |
| **Poppy Ergo Jr** | ~$300–500 | 6 DOF 单臂（3D 打印） | Python + snap! / V-REP | GPL v3 | 中 |

### 2.1 Microduck（主角）

- **URL**：https://pollen-robotics.com/microduck/  · https://github.com/pollen-robotics/microduck
- **价格**：$399（2025 预售 / 出货）
- **开源**：软硬件全开源（CAD、BOM、固件、训练栈）；训练框架用 mjlab（MuJoCo Warp）+ PPO（rsl_rl），策略 50 Hz。
- **核心硬件**：14 × Dynamixel XL330 伺服、~25 cm 高、~800 g、3D 打印躯干 + IMU + BAM actuator 模型（电压驱动 + 摩擦 DR + backlash）。
- **主要能力**：平地行走、上下坡、头部姿态跟踪、转弯、standup、sit-stand、轮式跪走（roller 变体）。
- **训练 / 部署**：mjlab 跑 4096 4096 1000 iter → ONNX（含 obs 归一化）→ 板端 50 Hz 部署。
- **学习曲线**：有 RL 基础 2–4 周（仿→真 sim2real 闭环）；零基础先学 mjlab 例程（microduck 仓库自带 walk / standup 演示）。

> **Microduck 的"独一份"卖点**：同价位唯一同时具备（a）真实腿足（b）端到端 RL 训练栈（c）社区级 sim2real 流程的项目。

### 2.2 SO-ARM100 + LeRobot

- **URL**：https://github.com/huggingface/lerobot  · https://github.com/TheRobotStudio/SO-ARM100
- **价格**：DIY 单臂 ~$100（含 3D 打印件 + 12 × STS3215 伺服），双臂 ~$200–300。
- **开源**：完全开源，LeRobot（Apache 2.0）一行脚本可训 ACT、DP3、SARM 等 VLA 模型。
- **核心硬件**：6+1 DOF（含夹爪），12-bit 磁编码伺服，主控 USB 串口。
- **能力**：抓取、装配、插 USB、推物体、模仿学习（手机 / VR 示教）。
- **训练 / 部署**：LeRobot 自带仿真（MuJoCo、AlohaTransfer）+ 真机示教数据采集。
- **学习曲线**：零基础 1–2 天跑通"示教 → 训练 → 回放"。

### 2.3 Reachy Mini（Pollen Robotics）

- **URL**：https://www.pollen-robotics.com/reachy-mini/
- **价格**：Lite $299（有线，需外接主机）/ Wireless $449（内置 Raspberry Pi 4）。
- **开源**：软件 Apache 2.0，硬件 CC BY-NC-SA。
- **核心硬件**：28 cm 高、1.5 kg；6 DOF 头部 + 360° 躯干旋转；宽视角相机 + 4 麦克阵列 + 5W 扬声器；2 个活动触角 + LED 表情眼。
- **能力**：对话 / 视觉问答（HF Transformers 1.7M+ 模型直接跑）、遥操作教学、桌面 demo 录制。
- **训练 / 部署**：Python SDK（`pip install reachy-mini`）+ HF Spaces 集成，无需 RL。
- **学习曲线**：纯对话 + 视觉，1 天可玩，深度学习路径取决于上层模型。

### 2.4 Poppy（Inria / Flower Robotics）

- **URL**：https://www.poppy-project.org/
- **价格**：Poppy Ergo Jr 套件约 €350（不含 3D 打印机）；Poppy Torso / Humanoid 自购物料 ~$2k–$5k。
- **开源**：硬件 CAD + 软件 GPL v3；Python + Snap! 可视化。
- **能力**：可拼装形态（桌面单臂 / 双臂 / 人形），教学为主。

### 3.1 Stanford Pupper

- **URL**：https://github.com/stanfordroboticsclub/StanfordQuadruped  · https://pupper.readthedocs.io/
- **价格**：自购零件 ~$600（含 Pi + 12 × JX CLS6336HV 舵机），MangDang 整组 ~$899。
- **开源**：全开源（CAD、BOM、Python 控制栈），1.2 kg / 5200 mAh 2S LiPo。
- **能力**：walk / trot / hop / jump / run；PS4 手柄遥操作；支持改装多种步态（bound、gallop）。
- **训练 / 部署**：PyBullet 仿真 + 真机 PD 控制栈，没有原生端到端 RL（社区有 minicheetah-like sim2real 移植）。
- **学习曲线**：装配 4–10 小时；改步态算法 1–2 周。

### 3.2 MIT Mini Cheetah（开源软件 / 闭源硬件）

- **URL**：https://github.com/mit-biomimetics/Cheetah-Software  · https://news.mit.edu/2018/mit-mini-cheetah-robot-0919
- **价格**：单台商业不可购，学术合作可复刻 ~$10k+；硬件 CAD 开源。
- **开源**：软件 BSD、硬件设计开源，但官方不卖整机；论文 / 视频中跑 backflip、side flip、跳跃。
- **训练 / 部署**：MIT 自家 MPC + Convex MPC；社区有 issaclab / mujoco 移植（legged_gym、extreme-parkour）。

### 3.3 Open Dynamic Robot Initiative — Solo

- **URL**：https://open-dynamic-robot-initiative.github.io/
- **价格**：单台物料 ~$15k–30k（SEA 直驱 + 力矩传感），机构合作可采购。
- **开源**：机械 / 电气 / 控制全开源；与 MPI-IS + NYU 联合；含 Solo 8 / Solo 12（8 / 12 DOF 四足）+ Torque-controlled 机械臂。
- **能力**：跑跳、后空翻、可触地力矩全闭环。
- **学习曲线**：需要电机驱动 + 实时控制基础；研一 1–2 学期。

### 3.4 Unitree Go2

- **URL**：https://www.unitree.com/go2/
- **价格**：Go2 $1,600 / Go2 EDU $2,800 / Go2 W（轮足）$2,800+（2024）。
- **核心**：12 DOF（3 × 4）；自重 ~8 kg；最大速度 ~2.5 m/s；最大关节扭矩 45 N·m；续航 2–4 h。
- **开源**：unitree_sdk2_python（BSD），社区有 legged_gym / isaaclab 移植（异构 GPU 需重写）；LiDAR + RealSense 可选。
- **能力**：走、跑、爬楼梯、巡检、语音跟随、机器狗入门科研。

### 3.5 TurtleBot 3 Burger

- **URL**：https://emanual.robotis.com/docs/en/platform/turtlebot3/overview/
- **价格**：~$550（含 Pi 4、OpenCR、LDS-01 LiDAR、3,000 mAh 电池）。
- **能力**：SLAM / Nav2 / 多机编队；ROS 1 Noetic + ROS 2 Humble；CB 级重负载教学标杆。

### 3.6 myCobot 280 / xArm Lite 6 / Trossen WidowX AI

- **共同特征**：6 DOF 桌面机械臂；ROS / MoveIt / Python SDK 全套；视觉 + 夹爪 + 气泵可选。
- **WidowX AI** 是 LeRobot 官方推荐训练目标（500 Hz 力矩环 + UDP 控制流），$4.5k 起，是"中端科研臂"的事实标准。

### 4.1 ALOHA / Mobile ALOHA（Stanford）

- **URL**：https://tonyzhaozh.github.io/aloha/  · https://mobile-aloha.github.io/
- **价格**：原版 ALOHA（静态双臂）整机物料 ~$20k；ALOHA 2 升级后 ~$120k；Mobile ALOHA（带移动底盘 + 厨房动作数据集）整机 ~$32k。
- **能力**：拧螺丝、插 USB、系鞋带、叠衣服、做饭（mobile）；ACT / Diffusion Policy / SARM 系列论文基线。
- **训练 / 部署**：以模仿学习（行为克隆）为主，少量 RL fine-tune；LeRobot 直接支持 ALOHA 配置。

### 4.2 Franka Panda（Franka Robotics）

- **URL**：https://www.franka.de/  · https://github.com/frankaemika/libfranka
- **价格**：新机 $10k–15k+，二手常见 $4k–8k（科研机构退役货）。
- **形态 / DOF**：7 DOF 全关节力矩感知（torque sensing in every joint）；重复定位 ±0.1 mm；ROS / MoveIt / Drake / Isaac Lab 生态最深。
- **注意**：Franka Robotics 2024 申请破产，重售市场和开源驱动（libfranka BSD）仍然活跃。

### 4.3 Unitree G1

- **URL**：https://www.unitree.com/g1
- **价格**：G1 基础款 $13,500 起；EDU 升级款（43 DOF + 力控手）约 $16k–20k。
- **规格**：132 cm / 35 kg；23 DOF（基配）/ 43 DOF（EDU）；膝关节扭矩 90–120 N·m；9000 mAh 电池，续航 ~2 h；含 RealSense + 4 麦克 + 5W 喇叭 + LiDAR；OTA 持续升级 + UnifoLM（大模型）集成。
- **开源**：unitree_sdk2 + isaaclab 移植（社区活跃）；自重 / 成本 / 生态综合下来是"个人能买得起的全尺寸人形"。

### 4.4 Reachy 2（Pollen Robotics）

- **URL**：https://www.pollen-robotics.com/reachy2/  · https://github.com/pollen-robotics/reachy-sdk
- **价格**：$19,990 起（躯干 + 双臂 + 头）。
- **开源**：软件 Apache 2.0，硬件结构 / CAD 开源。
- **能力**：双臂 + 头 + 轮式底盘；适合 embodied AI、对话、VLA 训练；官方推荐 mjlab 训练栈。

### 4.5 Hello Robot Stretch 2

- **URL**：https://www.hellorobot.com/
- **价格**：Stretch RE1 $17,950 / Stretch 2 $20,950。
- **能力**：室内移动 + 7 DOF 臂 + 触觉夹爪 + 1.3 MP 头相机；ROS 2 开源；适合家庭辅助、移动操作研究。

### 5.1 Unitree H1

- **URL**：https://www.unitree.com/h1/
- **价格**：~ $90k（首发定价，2024–2025 区间）。
- **规格**：180 cm / 47 kg；19 DOF（腿 5+5 + 臂 4+4 + 腰 1）；最大速度 3.3 m/s（人形机器人世界纪录）；M107 PMSM 关节；膝 360 N·m / 髋 220 N·m / 踝 59 N·m；864 Wh 电池快拆；MID-360 LiDAR + D435 深度相机。
- **开源**：SDK 部分开源，模型 / 控制器不开源；isaaclab 移植活跃。

### 5.2 Boston Dynamics Spot

- **URL**：https://www.bostondynamics.com/products/spot
- **价格**：基础 ~$75k（公司不公开标价，需询价）；含 Spot Arm + 控制器 + 软件可达 $150k+。
- **能力**：12 DOF 四足 + 5 DOF 机械臂；楼梯 / 斜坡 / 雪地 / 室内建图（自带 LiDAR + RGB-D）；Python / C++ SDK；ROS 包（spot-sdk，BSD）。
- **限制**：高机动性任务（跑酷）不开源；学术机构通过 Spot Academic Kit（SAK）合作可远程跑实验。

### 5.3 ANYbotics ANYmal C / ANYmal X

- **URL**：https://anybotics.com/
- **价格**：不公开，业界估计 $150k–300k+；ANYmal X（防爆版 Zone 1 / Zone 2）更贵。
- **能力**：工业巡检（炼厂、海上平台、矿山）；自主导航 + 异常上报；自重 ~50 kg；IP67。

## 9. Microduck 在生态中的位置

把上面这张表当成"价格 × 形态"二维地图：

- **横轴（价位）**：仿真（$0） → 桌面臂（$100） → 桌面伴 / 桌宠（$300） → **Microduck（$399，唯一有腿）** → 桌面全栈（$1k–5k） → 科研级（$5k–30k） → 商业级（$30k+）。
- **纵轴（能力 / 部署门槛）**：纯仿真 → 桌面玩具 → **真实 leg + 端到端 + sim2real**（Microduck 所在层） → 工业级。

结论：**Microduck 是"RL + 腿足 + 端到端"路径上能买到的最低门槛实物。**

- 比它便宜的：
  - 仿真（MuJoCo / Isaac Lab / mjlab，$0）；
  - 桌面臂 SO-ARM100（无腿，$100）；
- 比它便宜的腿足实物：几乎没有 —— Stanford Pupper 自购件可压到 $600，但属于四足 DIY 路线（PD 控制 + 无原生端到端 RL）。
- 同价位唯一对手：**Reachy Mini**（$299/$449）但它是无腿桌面头 + 对话路线。

所以：**Microduck = "我想在 $500 之内亲手跑完 sim2real 全链路"的唯一现实选择。**

## 11. 选购注意事项（容易踩的坑）

1. **价格 ≠ 能力**：Trossen WidowX AI $4.5k 在 LeRobot 上比某些 $15k 桌面臂更易用；Unitree G1 $13.5k 已能覆盖很多 H1 的演示场景。
2. **开源 ≠ 免费**：Microduck、Reachy 2、ALOHA 硬件 CAD 全开源，但 BOM / 训练数据 / 部署栈仍要付费；商业产品（Spot / Atlas）的"开源 SDK"只是控制接口，控制 / 模型 / 训练栈通常闭源。
3. **控制频率是分水岭**：500 Hz 以下桌面级（PD 控位为主）跑 RL 微调很容易；1 kHz 力矩环以上（Franka、ODRI Solo）才适合高动态接触任务。
4. **sim2real 不等于"训练一次就行"**：Microduck 同价位优势在于训练栈与硬件一体；ALOHA / WidowX 单独买硬件还需自己跑 sim2real 工具链。
5. **续航 / 维修 / 二手价值**：Unitree 系量产 + 全球代理 + 配件供应链成熟；小众项目（Pupper 自复刻）坏了要自己修。
