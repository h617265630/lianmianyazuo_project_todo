### 资源

## 3. 机器人学基础

### 必会概念
| 概念 | 在鸭子里对应 |
|---|---|
| 刚体 / 自由度 (DOF) | 14 主动 + 1 鸟喙 |
| 关节 / 运动链 | hip → knee → ankle |
| 正运动学 | 关节角 → 末端位置 |
| 雅可比矩阵 | 关节速度 → 末端速度 |
| 动力学 | 力矩 = M(q)q̈ + C(q,q̇)q̇ + G(q) |
| 接触 / 摩擦 | 脚底与地面 |
| 步态 / ZMP | 双足稳定行走 |

### 推荐书
- 《Modern Robotics》（Kevin Lynch）——免费 PDF，理论 + 代码
- 《Introduction to Autonomous Mobile Robots》（Siegwart）

### 练习
- 在 MuJoCo 里随便动一个关节，看 body 怎么运动
- 算一算鸭子站立时膝关节需要的力矩（粗略）

## 4. MuJoCo / 物理仿真

### 必会
- MJCF（XML）：body、joint、geom、actuator、sensor
- 接触模型：condim、friction、solref、solimp
- 域随机化（DR）：uniform / loguniform、operation="add/scale"

### 推荐练习
1. **修改鸭子高度**：在 `scene.xml` 改地形，测步态稳定性
2. **加一个新传感器**：在 `sensors.xml` 加一个 `touch`，看 obs 维度怎么变
3. **加一个新 body**：在 MJCF 加一个"尾巴"，看能不能训"摇尾巴"

### 资源
- [MuJoCo 官方文档](https://mujoco.readthedocs.io/)
- [mjlab 仓库](https://github.com/mujocolab/mjlab)——鸭子用的框架
- [MuJoCo Menagerie](https://github.com/google-deepmind/mujoco_menagerie)——各种机器人模型

## 5. 强化学习（核心）

### 必会概念
| 概念 | 一句话 |
|---|---|
| Markov Decision Process | (S, A, P, R, γ) |
| 策略 π(a|s) | 状态到动作的分布 |
| 价值函数 V(s) | 从这个状态出发期望回报 |
| Q 函数 Q(s,a) | 状态动作对的价值 |
| 优势函数 A(s,a) | 比平均好多少 |
| 策略梯度 ∇J | 怎么改参数让期望回报变大 |
| PPO | 限制每次更新幅度的策略梯度 |
| GAE | 优势函数估计 |
| on-policy / off-policy | 用自己跑的数据 vs 用别人的 |
| replay buffer | 存历史 transition |

### 推荐书 / 课程
- **Sutton & Barto《强化学习（第二版）》**——圣经，免费
- **Spinning Up**（OpenAI）——PPO 实现教学
- **Stable Baselines3** 文档——工业级 RL

### 在鸭子里的对应实现
- 仓库用 rsl_rl 的 PPO（来自 ETH 的腿足机器人框架）
- obs = 61 维，action = 14 维
- 4096 个并行 env，24 步 / iter

### 推荐练习
1. **调 reward weight**：在 `microduck_velocity_env_cfg.py` 改一个权重，看曲线
2. **看 GAE λ**：在 PPO cfg 里改 `lambda`，观察 sample efficiency
3. **加一个新观测**：加一个"头部离地高度" obs，看步态是不是更稳
4. **自己写一个 reward**：模仿 `mdp.py` 加一个 `head_idle_bonus`

## 6. sim2real（鸭子最核心的难点）

### 必会
- 域随机化（DR）：电压、摩擦、质量、延迟、噪声
- 系统辨识：测真实伺服响应 → 拟合 BAM 参数
- Backlash / 间隙 / 死区建模
- 观测 / 动作归一化
- 真实测试循环：仿真训 → 部署 → 测 → 改 DR → 重训

### 推荐资料
- 仓库 `AGENTS.md` —— 整本书的精华，特别是"Sim2real footguns"小节
- [sim-to-real-transfer.org](https://sim-to-real-transfer.org/)
- ETH ASL 的 ANYmal 论文

### 推荐练习
1. **加一个新 DR 项**：在 `events` cfg 加一个"随机头部质量"
2. **测真实伺服响应**：如果有真 XL330，跑 `scripts/validate_bam_testbench.py`
3. **测量 dt latency**：用示波器测指令发出到电机运动的时间

## 7. 自定义任务（进阶）

### 推荐练习
1. **加一个新 episodic 任务**：模仿 `microduck_bow_env_cfg.py` 加一个"鞠躬"
2. **改写 obs layout**：把 61D 改成 50D（看能不能训出更小的策略）
3. **蒸馏**：把 7 个 slot 的策略蒸馏成一个 ONNX，测试推理时间

## 8. 上位机 / daemon（如果你想做产品）

### 必会
- Rust 基础（鸭子 daemon 是 Rust 写的）
- IPC：Unix socket、protobuf、JSON-RPC
- systemd 服务管理
- OTA / 签名 / 回滚

### 推荐练习
- 读 `pollen-robotics/microduck` 仓库的 `robotd` 源码
- 自己用 Python 写一个最小 daemon：监听 socket → 转发到 mock duck
- 写一个 systemd unit 文件

## 9. PCB 与嵌入式（硬件路线）

### 必会
- STM32 / RP2040 编程（HAL / Pico SDK）
- I2C / SPI / UART / CAN
- PWM 控制舵机（不用 Dynamixel 协议）
- 基本电路：buck 电源、LDO、ESD 保护

### 推荐资源
- 《Making Embedded Systems》（Elecia White）
- STM32 HAL 官方教程
- [Phil's Lab](https://www.youtube.com/@PhilsLab) YouTube
- EEVblog（硬件设计）

### 推荐练习
1. **点亮一个 LED**：用 STM32 Nucleo
2. **PWM 控制 SG90**：用定时器输出 50 Hz PWM
3. **读 IMU**：用 I2C 读 MPU6050，输出到串口
4. **Dynamixel 通信**：用 USB2Dynamixel + Python SDK 控制一个 XL330

---

## 10. 机械 / CAD（如果要自己造一台）

### 必会
- Onshape / Fusion 360（参数化建模）
- 3D 打印件设计（公差、拔模、支撑）
- 总成本估算 / BOM 管理
- 装配公差

### 推荐练习
1. **设计一个简单 2 DOF 腿**：用 Onshape
2. **打印 + 装伺服 + 接线**：能站起来就算成功
3. **3D 打印鸭子外壳**：仿照现有 STL，缩小到 10 cm 高

## 11. 学习路线总结表

| 阶段 | 时间投入 | 目标 | 在鸭子上的产出 |
|---|---|---|---|
| 1. Python 工程 | 1 周 | 熟悉 dataclass / uv | 读懂 `microduck_constants.py` |
| 2. Linux | 1 周 | 会用 systemd / journal | 部署一个简单 daemon |
| 3. 机器人学 | 4 周 | 懂 DH / 动力学 | 算站立力矩 |
| 4. MuJoCo | 2 周 | 会改 MJCF | 改地形、加传感器 |
| 5. RL 基础 | 8 周 | 懂 PPO / GAE | 改 reward、调超参 |
| 6. sim2real | 4 周 | 懂 DR / 系统辨识 | 加新 DR 项 |
| 7. 自定义任务 | 4 周 | 训一个新动作 | 加一个 episodic |
| 8. Daemon | 4 周 | Rust + IPC | 写最小 daemon |
| 9. PCB | 8 周 | STM32 + 总线 | 控制 1 个伺服 |
| 10. 机械 | 8 周 | CAD + 3D 打印 | 一台简化版鸭子 |

**总计 ~ 1.5 年业余时间** 可以达到"能造一台简化版鸭子 + 训它走起来"的水平。
