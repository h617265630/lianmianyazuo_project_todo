Microduck（主角）

  • URL：pollen-robotics.com/microduck/ · github.com/pollen-robotics/microduck
  • 开源：软硬件全开源；训练框架用 mjlab（MuJoCo Warp）+ PPO（rsl_rl），策略 50 Hz
  • 核心硬件：14 × Dynamixel XL330 伺服、~25 cm 高、~800 g
  • 主要能力：平地行走、上下坡、头部姿态跟踪、转弯、standup、sit-stand、轮式跪走
Microduck 的"独一份"卖点：同价位唯一同时具备（a）真实腿足（b）端到端 RL 训练栈（c）社区级 sim2real 流程的项目。

9. Microduck 在生态中的位置

把上面这张表当成"价格 × 形态"二维地图：
  • 横轴（价位）：仿真（$0） → 桌面臂（$100） → 桌面伴 / 桌宠（$300） → Microduck（$399，唯一有腿） → 桌面全栈（$1k–5k） → 科研级（$5k–30k） → 商业级（$30k+）
  • 纵轴（能力 / 部署门槛）：纯仿真 → 桌面玩具 → 真实 leg + 端到端 + sim2real（Microduck 所在层） → 工业级

结论：Microduck 是"RL + 腿足 + 端到端"路径上能买到的最低门槛实物。

  • 比它便宜的：仿真（MuJoCo / Isaac Lab，$0）；桌面臂 SO-ARM100（无腿，$100）
  • 比它便宜的腿足实物：几乎没有
  • 同价位唯一对手：Reachy Mini（$299/$449）但它是无腿桌面头 + 对话路线

10. 推荐学习组合（按路径）

路径 A：全栈通用路线（最广覆盖）

  1. Microduck（$399）—— 学 RL + sim2real + 双足
  2. Unitree G1（$13.5k+）—— 学全尺寸人形 + 社区 + 量产
  3. （可选）Reachy 2（$19,990+）—— 学双臂 + embodied AI

路径 B：操作专项路线（机械臂方向）

  1. SO-ARM100 + LeRobot（$200）—— 学模仿学习 + VLA
  2. ALOHA / Mobile ALOHA（$20k–32k）—— 学双臂操作 + 公开数据
  3. Franka Panda（二手）（$4k–8k）—— 学力矩环 + ROS

路径 C：学术控制路线（控制 / 强化学习方向）

  1. Microduck（$399）—— 学 sim2real + RL
  2. Open Dynamic Robot Initiative Solo（$15k–30k）—— 力学建模 + 力矩闭环
  3. MIT Mini Cheetah（自复刻）（$10k+）—— MPC + 高机动性

11. 选购注意事项（容易踩的坑）

  1. 价格 ≠ 能力：Trossen WidowX AI $4.5k 在 LeRobot 上比某些 $15k 桌面臂更易用
  2. 开源 ≠ 免费：Microduck、Reachy 2、ALOHA 硬件 CAD 全开源，但 BOM / 训练数据 / 部署栈仍要付费
  3. 控制频率是分水岭：500 Hz 以下桌面级跑 RL 微调很容易；1 kHz 力矩环以上才适合高动态接触任务
  4. sim2real 不等于"训练一次就行"：Microduck 同价位优势在于训练栈与硬件一体
