06 · 学习路线 —— 从这只鸭子出发，能学什么、怎么学

推荐路线以"做中学"为主，每一阶段都有具体的练习任务。

0. 学习路径总览

            ▲  "我能造一台自己的"
            │     PCB + 嵌入式固件（10）
            │  "我能让它思考"
            │     强化学习核心（6, 7）
            │  "我能看到它动"
            │     MuJoCo + 机器人学基础（3, 4, 5）
            │  "我会用 Python"
            │     Python 工程基础（1, 2）
            └──────────────────────────────────►

1. Python 与工程基础

必会

  • Python 类型注解、@dataclass、@configclass
  • pathlib、argparse / tyro
  • Git 基础：commit、branch、rebase、diff
  • uv 包管理（uv add、uv sync、uv run）

3. 机器人学基础

概念在鸭子里对应
刚体 / 自由度 (DOF)14 主动 + 1 鸟喙
关节 / 运动链hip → knee → ankle
正运动学关节角 → 末端位置
雅可比矩阵关节速度 → 末端速度
动力学力矩 = M(q)q̈ + C(q,q̇)q̇ + G(q)
接触 / 摩擦脚底与地面

4. MuJoCo / 物理仿真

必会

  • MJCF（XML）：body、joint、geom、actuator、sensor
  • 接触模型：condim、friction、solref、solimp
  • 域随机化（DR）：uniform / loguniform、operation="add/scale"

5. 强化学习（核心）

概念一句话
Markov Decision Process(S, A, P, R, γ)
策略 π(a|s)状态到动作的分布
价值函数 V(s)从这个状态出发期望回报
优势函数 A(s,a)比平均好多少
策略梯度 ∇J怎么改参数让期望回报变大
PPO限制每次更新幅度的策略梯度
GAE优势函数估计

6. sim2real（鸭子最核心的难点）

必会

  • 域随机化（DR）：电压、摩擦、质量、延迟、噪声
  • 系统辨识：测真实伺服响应 → 拟合 BAM 参数
  • Backlash / 间隙 / 死区建模
  • 观测 / 动作归一化

11. 学习路线总结表

阶段时间投入目标在鸭子上的产出
1. Python 工程1 周熟悉 dataclass / uv读懂 microduck_constants.py
2. Linux1 周会用 systemd / journal部署一个简单 daemon
3. 机器人学4 周懂 DH / 动力学算站立力矩
4. MuJoCo2 周会改 MJCF改地形、加传感器
5. RL 基础8 周懂 PPO / GAE改 reward、调超参
6. sim2real4 周懂 DR / 系统辨识加新 DR 项
7. 自定义任务4 周训一个新动作加一个 episodic
8. Daemon4 周Rust + IPC写最小 daemon
9. PCB8 周STM32 + 总线控制 1 个伺服
10. 机械8 周CAD + 3D 打印一台简化版鸭子

总计 ~ 1.5 年业余时间 可以达到"能造一台简化版鸭子 + 训它走起来"的水平。
